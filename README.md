## ✨ О проекте

«Точка памяти» — это пространство, где воспоминания обретают цифровую форму.

Сервис позволяет создать индивидуальную страницу памяти, посвящённую близкому человеку. Такая страница становится местом, куда можно возвращаться, делиться воспоминаниями и сохранять важные моменты жизни.

Мы стремимся объединить современные технологии и человеческую память, сохраняя особую атмосферу уважения, тепла и заботы.

## 🚀 Возможности

- 🕯️ Создание персональных страниц памяти.
- 📷 Сохранение фотографий и памятных материалов.
- 📝 Публикация историй, биографии и воспоминаний.
- 🔗 Использование QR-кода для быстрого доступа к странице памяти.
- 🌐 Возможность поделиться страницей с близкими.
- 💛 Индивидуальное оформление страницы.
- 📱 Удобный доступ с компьютеров, планшетов и смартфонов.

## 📱 Административное приложение

В рамках развития проекта разрабатывается отдельное Android-приложение для администраторов.

Планируемые возможности:

- Защищённая авторизация администраторов.
- Подтверждение первого входа через Telegram.
- Просмотр заявок с сайта.
- Управление статусами заявок.
- Общий архив завершённых заявок.
- Поиск и фильтрация заявок.
- Синхронизация данных между администраторами.

Приложение разрабатывается отдельно от основного сайта.

## 🛠️ Технологии

Технологический стек проекта формируется в процессе разработки.

Планируемые технологии:

- **HTML, CSS, JavaScript** — существующий сайт.
- **Kotlin** — Android-приложение.
- **Jetpack Compose** — интерфейс Android-приложения.
- **Node.js / TypeScript** — серверная часть.
- **PostgreSQL** — хранение данных.
- **Telegram Bot API** — уведомления и подтверждение входа.

## 🔐 Безопасность

Безопасность пользовательских и административных данных является важной частью проекта.

Предусматриваются:
- Защищённое соединение HTTPS.
- Серверная проверка прав доступа.
- Безопасное хранение паролей.
- Ограничение доступа к административным функциям.
- Защита конфиденциальных данных и API-ключей.

## 📌 Статус проекта

**Проект находится в разработке.**

Основные направления работы:
- Развитие сайта.
- Интеграция серверной части.
- Создание административного Android-приложения.
- Разработка системы управления заявками.

Функции, находящиеся в разработке, не следует считать уже реализованными.
