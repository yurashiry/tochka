# Точка памяти

**Точка памяти** — сервис создания персональных цифровых мемориалов, посвящённых близким людям.

Сайт позволяет ознакомиться с услугами, выбрать подходящий тариф и оставить заявку на создание мемориальной страницы.

---

## 🌐 Сайт

Сайт размещается на GitHub Pages.

- Главная страница: `index.html`
- Политика конфиденциальности: `privacy.html`
- Изображения и графические материалы: `assets/`

## ✨ Возможности сайта

- Адаптивный дизайн для компьютеров, планшетов и смартфонов.
- Анимации и плавные визуальные переходы.
- Презентация услуг и тарифов.
- Форма подачи заявки.
- Отдельная страница политики конфиденциальности.
- Локальное хранение изображений и ресурсов проекта.
