# Точка памяти — статическая версия для GitHub Pages

## Публикация
1. Загрузите содержимое этой папки в корень GitHub-репозитория.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`.
4. Сохраните настройки и дождитесь публикации.

## Важно
- Внешние зависимости Chatium Runtime удалены из `index.html`.
- Изображения, присутствующие в полученном архиве, лежат в `assets/`.
- Тарифы обновлены: 10 000 ₽, 15 000 ₽ и 20 000 ₽.
- Форма пока является визуальной заготовкой и отключена: backend ещё не подключён.
- Экспорт Chatium содержал только экран успешной отправки, но не исходную разметку полей формы. Поэтому поля восстановлены как предварительная форма; после согласования backend-интеграции её можно подключить.
- В исходнике присутствовали внешние изображения Chatium, которые не были включены в архив. Для favicon/social preview использован локальный логотип из переданных файлов.
- `privacy.html` — временная заглушка, её нужно заменить утверждённой политикой конфиденциальности до публикации.

Проверьте визуально все разрешения после загрузки на GitHub Pages.
